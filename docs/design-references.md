# HP デザインリファレンス集 — Claude Design への組み込みガイド

実在サイトから「リッチで、お金がかかっていて、AI っぽくない」デザインの要素を抽出し、Claude Design のトークン・コンポーネントに翻訳するためのドキュメント。

> **「AI っぽい」の定義(このプロジェクトで避けるもの)**
> 紫→青グラデーション / glassmorphism / 汎用 3D ブロブ / 絵文字見出し / 中央揃え 3 カードの均等グリッドの反復 / Inter・Poppins だけのタイポグラフィ / undraw 風フリーイラスト / 過剰な角丸と影 / 常時動き続けるパーティクル

---

## 1. リファレンスサイト(10 選)

### 1. Anthropic — https://www.anthropic.com
**位置づけ**: Claude Design の原点。
**借りるもの**: アイボリー背景の「紙」の質感、セリフ見出し × サンセリフ本文、余白のリズム、手仕事感のあるイラストのトーン(汎用 3D を使わない)。
**組み込み**: すでに §2 ファウンデーションの基礎(`ivory-*` / `terracotta-*` / セリフ見出し)として反映済み。

### 2. Claude — https://claude.com
**位置づけ**: 同じデザイン言語のプロダクトマーケティング適用例。
**借りるもの**: アクセント色を CTA と強調のみに絞る節度、プロダクト UI スクリーンショットを角丸カード + 細ボーダーで「額装」する見せ方。
**組み込み**: `Card` の額装スタイル(border + 微小shadow)、アクセント使用ルール(1 画面 1〜2 箇所)をガイドライン化。

### 3. Mercury — https://mercury.com
**位置づけ**: 銀行サービスなのにラグジュアリーブランドの佇まい。「お金がかかって見える」の最良の教材。
**借りるもの**: セリフ系の大見出し(カスタム書体 Arcadia)、シネマティックで暗いフォトグラフィ、ページ途中に挿入される**ダークセクションによる緩急**、巨大なフッターワードマーク。
**組み込み**: `bg/inverse`(暖色系ダーク)トークン、`DarkBand` セクションコンポーネント、`MegaFooter`、Display XL タイプスケール。
**参考解説**: https://blakecrosley.com/guides/design/mercury

### 4. Aesop — https://www.aesop.com
**位置づけ**: ラグジュアリー EC の静けさ。色数の少なさが高級感を作る証明。
**借りるもの**: 低彩度・少色数パレット、控えめなアンダーライン主体のリンク/ボタン、小さめ本文 + 広い行間、写真の余白。
**組み込み**: `Button` の `quiet` バリアント(枠線なし・下線ホバー)、本文タイポ(15–16px / lh 1.8)、写真アートディレクション規定。

### 5. mymind — https://mymind.com
**位置づけ**: AI プロダクトなのに最も「AI っぽくない」サイト。温かく人間的。
**借りるもの**: セリフイタリックによる感情表現、コピー主導のレイアウト、雑誌のコラージュ感、遊び心のある区切り記号(✳ など)。
**組み込み**: display トークンに `italic` アクセント用法を追加(欧文のみ)、`Marquee` / 装飾記号の使用規定。

### 6. Polestar — https://www.polestar.com
**位置づけ**: ミニマル・プレミアムの極点。「余白がいちばん高い」。
**借りるもの**: セクションあたり 1 メッセージ、フルブリード画像、極端に大きいセクション余白、抑制されたモーション。
**組み込み**: セクション用スペーシング(`96 / 128 / 160px`)をスケールに追加、1 セクション 1 メッセージのレイアウト原則。

### 7. Oura — https://ouraring.com
**位置づけ**: プレミアムハードウェアの世界観。暗部 + 暖色ライトのシネマティック表現。
**借りるもの**: ダーク背景での数値の見せ方(大きなセリフ数字 + 小さなラベル)、スクロールに応じた静かなリビール。
**組み込み**: `StatBand` コンポーネント(セリフ大数字)、スクロールリビールのモーショントークン。

### 8. Pentagram — https://www.pentagram.com
**位置づけ**: エディトリアルグリッドの教科書。デザイン事務所の本気。
**借りるもの**: 12 カラムグリッド、罫線(hairline rule)による区切り、番号付きリスト・メタ情報(日付 / カテゴリの小さなキャップス)の階層。
**組み込み**: グリッドトークン(12col / gutter 24 / max 1440)、`Eyebrow`(小さなキャップスラベル)、`EditorialList`(番号付き大型リスト)。

### 9. Watershed — https://watershed.com
**位置づけ**: エンタープライズ SaaS でありながらセリフ書体と温かみを両立。B2B でもこの路線が成立する証明。
**借りるもの**: セリフ見出しとデータビジュアルの共存、深緑・アース系の落ち着いたセカンダリカラー。
**組み込み**: `olive-500` の使いどころ(データ/成功状態)の実例として参照。

### 10. Linear — https://linear.app
**位置づけ**: マイクロインタラクションのクラフト基準。**配色は借りない**(ダーク+グラデは AI っぽさ側)。
**借りるもの**: 150–250ms のホバー遷移、フォーカスリングの丁寧さ、変化は opacity / transform のみに限定する規律。
**組み込み**: モーショントークン(§3)の数値根拠。

## 2. 横断分析 — 「高そうに見える」サイトの共通項

1. **セリフの大見出し**: 全サイトが見出しにセリフ(またはカスタム書体)。サンセリフだけのサイトは 1 つもない
2. **背景は「白」ではない**: アイボリー、暖色ダークなど素材感のある地色。純白 `#FFFFFF` と純黒 `#000000` は不使用
3. **影ではなく罫線**: 区切りは 1px の hairline rule とタイポグラフィの階層で作る。ドロップシャドウにほぼ頼らない
4. **モーションは一種類**: fade + わずかな translateY のリビールだけ。それ以上動かさない
5. **緩急のあるページ構成**: 明るいセクションの間にダークセクションを 1 つ挟み、リズムを作る(Mercury / Oura)
6. **本物の写真 or 独自アート**: 汎用イラスト・フリー素材が 1 枚もない。予算感はほぼここで決まる

### 3.2 タイポグラフィ追加(ディスプレイスケール)

| トークン | 値 | 由来 |

### 3.6 コンポーネント追加(マーケティング層 = P1-M)

既存の P0/P1(アプリ UI)とは別レイヤーとして、HP 用コンポーネント群を追加:

| コンポーネント | 参照元 |
|---|---|
| `Eyebrow` | Pentagram |

| `Marquee`(低速テキストループ) | mymind |
| `EditorialList`(番号付き大型リスト) | Pentagram |

### 3.7 アートディレクション規定(Do / Don't)

**Do**: 実写(暖色グレーディング)/ 色面と活字による独自グラフィック / 罫線 / 図版番号(FIG. 01)などの誌面的ディテール
**Don't**: 冒頭の「AI っぽいの定義」に列挙したもの全部。写真が用意できない場合はフリー素材ではなく色面 + タイポで構成する
